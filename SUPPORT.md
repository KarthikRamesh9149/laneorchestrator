# Support

Use [GitHub Issues](https://github.com/KarthikRamesh9149/laneorchestrator/issues) for reproducible bugs and focused feature requests. Include a minimal objective, route flags, sanitized JSON output, operating system, Python version, and commit or release version.

Before filing an issue:

```bash
python3 scripts/healthcheck.py
sh scripts/validate.sh
```

For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md). Public issues must not contain secrets, private source code, access tokens, or exploit details.
