# Support

Use [GitHub Issues](https://github.com/KarthikRamesh9149/laneorchestrator/issues) for reproducible bugs and focused feature requests. Include a minimal objective, route flags, sanitized JSON output, operating system, Python version, and commit or release version. Remove secrets, access tokens, private paths, and private repository content.

Before filing an issue from a source checkout:

```bash
python3 scripts/healthcheck.py
sh scripts/validate.sh
```

For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md). Public issues must not contain secrets, private source code, private paths, access tokens, or exploit details.
