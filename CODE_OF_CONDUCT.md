# Code of conduct

Participation in this project requires respectful, constructive, and technically honest collaboration.

- Discuss code and evidence, not personal characteristics.
- Welcome questions and differing levels of experience.
- Do not harass, threaten, impersonate, or publish another person's private information.
- Do not pressure reporters to disclose vulnerabilities publicly before remediation.
- Assume good intent while still addressing unsafe behavior directly.

Project maintainers may edit or remove abusive content and restrict participation when needed to protect contributors. Report conduct concerns privately to the maintainer through the contact options on the GitHub profile rather than opening a public issue containing sensitive information.
