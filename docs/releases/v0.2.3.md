# LaneOrchestrator v0.2.3

This release adds a guided first-run setup command for the complete bundled profile set: four LaneOrchestrator control profiles plus 172 pinned VoltAgent specialists (176 profiles total).

Install the protected reviewed snapshot:

```sh
codex plugin marketplace add KarthikRamesh9149/laneorchestrator --ref v0.2.3
codex plugin add laneorchestrator@laneorchestrator
```

From the resolved plugin root, run `python3 -m laneorchestrator setup` in an interactive POSIX terminal or WSL session. Setup renders one combined preview, asks once for `y` or `yes`, applies control profiles before specialists, and verifies doctor and specialist status. It never prints raw plan tokens or approval digests. A specialist-stage failure retains the valid control installation so a later setup run can resume.

`python3 -m laneorchestrator setup --json` is a read-only readiness response for automation; it never prompts or mutates profile targets. The existing `profiles ... preview/apply` and `voltagent ... preview/apply` commands remain available for advanced, explicitly approved workflows.
