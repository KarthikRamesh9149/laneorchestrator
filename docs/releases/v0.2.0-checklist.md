# v0.2.0 operational release checklist

Candidate preparation does not check any item below. Complete these only in the operational release runbook with fresh, redacted evidence from the exact release commit.

- [ ] Confirm clean, synchronized `main` and record the release commit.
- [ ] Complete the full CI matrix without annotations.
- [ ] Generate and review benchmark evidence.
- [ ] Build and verify deterministic archives and generated `SHA256SUMS`.
- [ ] Complete isolated lifecycle and marketplace journeys.
- [ ] Complete the canonical security workflow and independent review; resolve blockers.
- [ ] Apply and verify the reviewed GitHub metadata, Discussions choice, and sole-`main` ruleset.
- [ ] Recheck pre-public gates after settings changes.
- [ ] Obtain authorization for visibility, then repeat public installation from an isolated home.
- [ ] Create the annotated `v0.2.0` tag, attach verified assets, and verify public links from an unauthenticated context.
