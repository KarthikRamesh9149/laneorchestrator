# LaneOrchestrator v0.2.2

This release bundles the pinned, MIT-licensed VoltAgent Codex specialist pack: 172 namespaced profiles that can be activated through a reviewed, approval-bound install plan. The control-plane routing profiles remain standalone, and specialist metadata cannot override the Luna, Terra, and Sol safety boundaries.

Install the protected reviewed snapshot:

```sh
codex plugin marketplace add KarthikRamesh9149/laneorchestrator --ref v0.2.2
codex plugin add laneorchestrator@laneorchestrator
```

After installation, use `$laneorchestrator` as normal. To add the bundled specialists to the host profile directory, first inspect `python3 -m laneorchestrator voltagent install preview --json`, then apply only with its bound token and matching approval digest.

After release creation, verify the tag, release workflow, `SHA256SUMS`, and artifact attestations directly. Security evidence is layered and bounded; it is not a claim of permanent security or complete semantic-risk coverage.
