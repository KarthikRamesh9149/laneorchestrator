# LaneOrchestrator v0.2.4

`v0.2.4` is a maintenance release prepared from the repository quality audit. It preserves the four control profiles and 172 pinned VoltAgent specialists while tightening the public release and lifecycle contract.

## Highlights

- Corrected compatibility documentation to separate the verified `v0.2.3` CI matrix from the evidence required for this and future revisions.
- Added explicit marketplace update and removal guidance. A pinned marketplace source does not silently move to a different release tag, and plugin removal does not remove managed profiles or configuration.
- Retained the separate, approval-bound profile lifecycle for global Codex state.

## Install

```sh
codex plugin marketplace add KarthikRamesh9149/laneorchestrator --ref v0.2.4
codex plugin add laneorchestrator@laneorchestrator
```

After installation, use `$laneorchestrator` from any workspace. From a resolved plugin root, `python3 -m laneorchestrator setup` provides one reviewed interactive installation for four control profiles and 172 bundled specialists.

## Verify before trusting a release

At release publication, verify the immutable `v0.2.4` tag, the release workflow, deterministic archives, `SHA256SUMS`, and GitHub artifact attestations. Security evidence is bounded: it supports informed review, but does not guarantee every environment or future change is risk-free.
